# Developer Portfolio - Abhishek Jaiswar

A modern, responsive, and dark-themed developer portfolio website built using pure **HTML5** and **CSS3**. The portfolio showcases personal profile details, technical skills, education, contact information, and highlighted projects in a clean grid and flexbox layout.

---

## 🌟 Key Features

- **Dark Theme UI**: Stylish `#1e1e1e` background palette with vibrant accent colors (`#FFBF00`).
- **Responsive Layout**: Two-column layout on desktop using CSS Grid, converting smoothly to single-column layouts on tablets and mobile devices.
- **Sticky Sidebar**: Quick access to profile image, role, contact info, and social links.
- **Interactive Navigation**: Smooth visual feedback and custom linear-gradient hover underline animations.
- **Card Hover Effects**: Micro-interactions with CSS transforms and dynamic shadows on skills and project cards.
- **Social & Contact Links**: Integrated links for Email, Phone, GitHub, LinkedIn, LeetCode, and X (Twitter).

---

## 🛠️ Built With

* **HTML5**: Semantic structure and page hierarchy.
* **CSS3**: Custom grid layouts, flexbox, custom scrollbars/transitions, and media queries for responsiveness.
* **Remix Icon & SimpleIcons**: Vectors and visual brand icons.
